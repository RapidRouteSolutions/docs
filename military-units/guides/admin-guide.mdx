# Administer your unit

Open [Settings → Units](https://rapidepr.com/settings/units). After your unit
request is approved, its management view provides member, billing and usage
controls.

## Members and roles

Add a member using the email address of an existing RapidEPR account.
The member must leave another current unit before joining yours.
Use member controls to remove a member or change an administrator role.

Removing a member ends access to your shared pool; it does not remove their
personal credits or generated content. Before leaving as the last administrator,
promote another member so someone can continue managing the unit.

## Credits and billing

The current interface offers:

| Option                      | Listed price                                         |
| --------------------------- | ---------------------------------------------------- |
| 1,000 credits               | $250                                                 |
| 3,000 credits               | $600                                                 |
| Custom credits              | Minimum 100; the interface advertises a 15% discount |
| Unit unlimited subscription | $750/month                                           |

Confirm the price and terms displayed at Stripe checkout. Payments appear in
the shared balance after processing. Contact support if a successful payment
does not appear; avoid submitting the same purchase repeatedly.

The unit pool/subscription is attempted before each member's personal access.
Review recorded member usage to plan purchases. Usage reporting does not expose
the text in members' packages.

## Subscription cancellation

Use the unit billing controls to cancel renewal or manage payment details.
Ordinary cancellation preserves access through the current paid period.
Deleting a member's personal account does not cancel unit billing.

## Help

Contact [support](https://rapidepr.com/settings/support) for payment,
ownership or membership problems. Return to the
[unit overview](/military-units/index).
