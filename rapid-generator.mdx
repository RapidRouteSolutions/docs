# Work in a package

Open [Rapid Generator](https://rapidepr.com/generator) from the sidebar.
Packages group your work for a person, evaluation period or award. A package
contains one branch and one type of writing.

## Create and use a package

1. Choose **New Package**.
2. Choose your branch, then a format under **Bullets & Statements** or **Awards & Decorations**.
3. Name the package so you can find it later.
4. Enter your accomplishment or award details. Select a section or rated rank
   when your chosen format requests one.
5. Generate, review the options, and copy the wording you want to use.

The output appears as it is generated. It can restart once while the system
attempts to improve its formatting. Wait for completion before treating a draft
as saved. Review names, dates, measurements, placeholders and form limits yourself.

## Keep useful drafts

Use favorites to keep preferred options in the package; a package supports up
to 25 favorites. You can rename or archive a package and choose another
available format within its branch and writing type. Earlier generations keep
their original format.

The **History** view holds older generations outside the package workflow.
Existing `/bullets` and `/awards` bookmarks now open Rapid Generator.

Deleting a package removes its container, not its generated source records.
It is not a data-erasure action. Archive a package if you want it out of your
active list but expect to reopen it.

## If generation fails

If your session expires, sign in again. If a stream stops, reopen the package
and check for a saved result before generating again: a connection failure
can happen after work has been saved. Contact support if the result or charge
is unclear.

See the [bullet guide](/bullet-generator/index), [award guide](/award-generator/index)
and [billing FAQ](/faq) for the next steps.
