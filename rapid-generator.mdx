# Organize your work with packages

A package keeps the drafts and favorites for one person's evaluation or award
in one place. Create a package for your own report, someone you supervise,
or a service member you are helping with an award.

Keep a separate package for each person and report period or award. For
example, "My 2026 EPB" and "Sgt Rivera - End-of-tour award" let you
find the right work without sorting through unrelated drafts.

Each package uses one branch and one type of writing. Within an evaluation
package, you can work on different sections of that person's report.

## Create a package

1. Open [Rapid Generator](https://rapidepr.com/generator) and choose New Package.
2. Choose the person's branch.
3. Select a format under Bullets & Statements or Awards & Decorations.
4. Name the package for the person and report period or award.
5. Enter the accomplishments and any details the format asks for, then generate.

For an evaluation, include what the person did and what changed as a result.
For an award, include their rank, name, duty title, unit and award period.
Choose the report section and rated rank when prompted.

## Compare drafts and save favorites

Drafts appear as they are generated. Wait for generation to finish, then
compare the options and copy the wording you want to use. Check names, dates,
numbers and placeholders before adding the text to the report.

Save useful options as favorites so you can find them while finishing the
package. Each package holds up to 25 favorites. You can generate more drafts
without losing earlier work.

## Find and manage your work

Open the Packages tab to return to a person's evaluation or award. You can
rename a package or change its format within the same branch and type of writing.

Archive a finished package to remove it from the active list. Archived
packages are read-only until you restore them.

The History tab contains standalone generations. Deleting a package removes
the package and its favorites. RapidEPR retains the generated records.

## If generation stops

Reopen the package and check for a saved draft before generating again.
If your session has expired, sign in again. Contact
[support](https://rapidepr.com/settings/support) if a draft or credit charge
is missing.

Read the [bullet guide](/bullet-generator/index) or
[award guide](/award-generator/index) for help with your next draft.
