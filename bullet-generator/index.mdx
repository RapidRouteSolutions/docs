## Write evaluation statements

Create an evaluation package for the person whose report you are writing.
Their drafts and favorites stay together while you work through the report's
sections.

Each bullet submission uses one credit and includes all the options it
generates. New accounts start with five credits.

## Generate a draft

1. Open [Rapid Generator](https://rapidepr.com/generator) and choose New Package.
2. Choose the person's branch, then a format under Bullets & Statements.
3. Name the package for the person and report period.
4. Describe what they did, their responsibility, and the result in up to 500 characters.
5. Select the rated rank and Area / Section when the format asks for them.
6. Choose Conservative, Moderate or Creative variation, then select Generate Bullets.
7. Compare the options, pin useful wording with the star button, and use Copy to clipboard.

Choose the format that matches the report you are writing. Air Force OPB
and EPB, Army NCOER and OER, and Navy EVAL and FITREP formats let you select
a specific section.

Most formats return three alternatives. Chief Eval returns comments grouped
by trait. Moderate is the default variation; it is also used in the examples below.

Before using a draft, check its names, dates, numbers and fit on the form.
Generated text can add claims or placeholders that were not in your input.
Replace placeholders with verified facts and remove claims you cannot support.
